# Domain features

À partir des prochains prompts, chaque fonctionnalité (auth, patient, doctor, appointments, needs, messaging, notifications, admin) sera organisée dans son dossier, hors de `src/app`. Les fichiers de `src/app` restent des entrées de navigation Expo Router.

Avant toute création d'écran : examiner la version responsive sur https://medilink-nu-ten.vercel.app/ à 360, 390 et 430 px et comparer la page Next.js et l'API. Si le site est inaccessible, documenter ce blocage.
